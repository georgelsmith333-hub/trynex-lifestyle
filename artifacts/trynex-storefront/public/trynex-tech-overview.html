🏗️ System Architecture

TryNex is a full-stack monorepo with a React storefront, Express API, PostgreSQL database, and a cloud-first deployment on Render. Everything lives in one pnpm workspace for easy coordination.

React 19 + Vite 7
TypeScript · Tailwind CSS v4 · Framer Motion · Radix UI · wouter routing
Backend
Express 5 · Node.js
TypeScript · 18+ route modules · JWT auth · Rate limiting · CORS protection
Database
PostgreSQL + Drizzle ORM
Non-destructive migrations · Auto-seeding · Type-safe queries · 12 tables
3D Engine
React Three Fiber + Three.js
GLB models · PBR materials · Real-time texture compositing · WebGL2
Storage
Cloudflare R2
S3-compatible object storage · Design assets · Order files · Image uploads
Deployment
Render.com
Auto-deploy from GitHub main · PostgreSQL managed DB · Free tier (1 region)

🚨 Things to Keep in Mind

  • Never auto-seed: autoSeedIfEmpty() only runs on empty DBs — existing data is never overwritten
  • Admin token security: Uses sessionStorage (not localStorage) — auto-clears when browser tab is closed
  • Migrations are safe: Always CREATE TABLE IF NOT EXISTS and ADD COLUMN IF NOT EXISTS
  • Render free tier: Server sleeps after 15 min inactivity — first request may take 30s to wake
  • R2 storage: Design images and order assets stored in Cloudflare R2, not on the server filesystem
  • GitHub PAT: The admin → Deployment → Push to GitHub uses a PAT stored in the Replit environment, not in code
  • Flash sale timer: Runs on BST (UTC+6) boundaries — midnight and noon reset the countdown automatically
