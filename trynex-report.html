Executive Summary
Business overview & platform highlights

TryNex Lifestyle is a Bangladeshi print-on-demand e-commerce platform that allows customers to design and order custom-printed apparel, accessories, and lifestyle products. The platform consists of a web storefront, an Express REST API, a PostgreSQL database, and an Expo mobile app — all managed as a single pnpm monorepo.

📱 Mobile App
Expo React Native app for iOS & Android. Shares API client with the web storefront. Full shopping experience, Design Studio, cart, checkout, and order tracking in a native wrapper.
🎨 Design Studio

Design Studio
Custom mockup engine — SVG compositing with garment photography

The Design Studio is TryNex's signature feature — a browser-native product customisation tool that gives customers a photorealistic preview of their design on each product. No external mockup service is used; all rendering happens client-side in real time.

🖼️ Garment Rendering Engine

Three rendering strategies depending on garment colour:

  • White / light colours: Two-layer multiply-blend. The full original photo renders with mix-blend-mode: multiply so the white background becomes transparent while all fabric texture, creases, and shadows remain perfectly photorealistic.
  • Near-black garments: Full dedicated dark photo (e.g. black-tshirt-front.png) renders directly with SVG drop-shadow filter. No cutout artifacts.
  • Mid-tone colours (navy, maroon, olive…): Transparent-background cutout PNG + SVG feFlood colour-tinting filter. The tint is masked to the garment silhouette via feComposite in2="SourceAlpha".
🔧 SVG Filter Pipeline (Tint)
filter desaturate (feColorMatrix)
  → flood colour (feFlood)
  → mask to alpha (feComposite)
  → multiply with base (feBlend)
  → restore alpha (feComposite)
drop-shadow (feDropShadow)
  → follows garment silhouette α

Design Studio Features

📤 Upload Image
JPG/PNG/WebP up to 10MB. Drag-and-drop or file picker. Images rendered as SVG <image> elements inside a bounded print zone. Resize, rotate, reposition handles via pointer events. Z-order management with layers panel.
🤖 AI Art Generation
Customers enter a text prompt; the API calls a configurable AI model (server-side, model-agnostic). Generated image URLs streamed back. Reference image upload for style transfer. Models listed dynamically from API.
🔤 Text Tool
Add custom text layers with font family (100+ Google Fonts), size, colour, bold/italic/underline, letter spacing, line height. Each text block is a draggable, scalable SVG element.
📋 Templates
Pre-built design templates stored per product category. One-click apply. Templates are admin-managed via the Admin Panel CMS. Customers can customise any template after applying.
👔 Product Switcher
Switch between T-Shirt, Hoodie, Long Sleeve, Mug, Cap, Waterbottle without losing the design. The print zone and mockup update; the design layers reflow to fit the new canvas. Front/Back toggle for apparel.
💾 Draft Saving
Designs auto-saved to localStorage as JSON (SVG elements + product selection + colour). Draft restoration on revisit. Logged-in users can save named drafts to the server. Drafts JSON-exported for order fulfillment.
💡
The Design Studio renderer is built entirely with inline SVG. There is no canvas/WebGL dependency for the 2D view. On desktop, an optional Three.js 3D preview renders the design on a photo-billboard mesh for extra realism. The SVG approach ensures pixel-perfect print export and universal browser compatibility.

Authentication & Security
Multi-layer auth, JWT, TOTP 2FA, rate limiting
🔐 Customer Auth
  • Registration: Email + password → Argon2id hash stored
  • Login: Password verify → JWT issued (HTTP-only cookie)
  • Google OAuth: google-auth-library verifies ID token → create/match account by google_id
  • Facebook OAuth: Access token verified → same flow
  • Guest mode: Session UUID issued, orders linked to session, convertible to account
  • Password reset: Time-limited token emailed via Nodemailer
🛡️ Admin Auth
  • Login: Username + password → session token (SHA-256 hashed in DB)
  • TOTP 2FA: Optional second factor via authenticator app (QR code setup, 6-digit verification)
  • Sessions: Listed, revocable individually or all-at-once
  • IP/UA logging: Every session records IP address + user agent
  • Master reset: Emergency password reset via secure env-var token

API Security Layers

🔒 Helmet.js
Sets 15+ HTTP security headers: Content-Security-Policy, X-Frame-Options, X-Content-Type-Options, Strict-Transport-Security, Referrer-Policy, Permissions-Policy.
⏱️ Rate Limiting
express-rate-limit applied globally + extra-tight on auth endpoints. Upstash Redis backend for distributed counters (prevents bypass on multi-process deploy).
🌐 CORS
Configured cors middleware with allowlist of origins (trynexshop.com, trynex-lifestyle-shop.pages.dev, localhost variants). Credentials included for cookie-based auth.
🧼 Input Validation
All request bodies validated with Zod schemas (@workspace/api-zod). Parse failures return structured 400 errors. Schema shared between API and client via workspace package.

AI Integration
Design generation, AI chat, admin AI operations
🎨 AI Design Generation

Customers enter a text prompt in the Design Studio's "AI Art" tab. The API streams image generation via GET /ai/generate using Server-Sent Events (SSE). The generated image is served as a temporary URL from GET /ai/ref/:filename. Users can also upload a reference image for style-guided generation via POST /ai/reference.

The AI model is configurable server-side — multiple providers are supported. Available models are queried dynamically via GET /ai/models.

💬 AI Chat

POST /ai/chat supports a conversational AI assistant accessible in the Design Studio. Helps customers with design ideas, colour suggestions, and print specifications.

Admin AI Developer: A separate admin-only developer chat (/ai/developer/chat) with access to a configurable set of tools, allowing automated admin operations via AI prompts. Includes context injection, multi-model support, and tool execution.

🤖 AI Admin Execute (aiExecute)

A sophisticated admin feature allowing AI-driven bulk operations. Flow:

  1. Preview: POST /admin/ai-preview — dry-run shows what changes would be made
  2. Execute: POST /admin/ai-execute — applies the changes, logs to activity_log
  3. Undo: POST /admin/ai-undo — reverts any AI-executed operation using activity_log old_value snapshots

Supports product bulk updates, coupon generation, category changes, and more.

🖼️ Product Image Storage
AI-generated product images and admin-uploaded images stored via POST /storage/product-image (requires admin auth). Images stored on a configurable S3-compatible bucket (AWS S3 SDK via @aws-sdk/client-s3). Pre-signed URLs generated for direct browser upload (@aws-sdk/s3-request-presigner).

Admin Panel
Full-featured CMS and operations dashboard

The admin panel is embedded in the storefront at /admin/* (protected by session token). It is a fully-featured back-office for managing every aspect of the TryNex business.

📊 Dashboard & Analytics
Real-time sales figures, order counts, revenue totals, top-selling products, customer growth, and revenue time-series charts (Recharts). Export to CSV.
📦 Order Management
List, filter, search orders. Update status (Pending → Processing → Shipped → Delivered → Cancelled). Update payment status (Pending → Paid → Refunded). Add internal notes. View full order details including custom design JSON. Telegram notification on new orders.
🛍️ Product CMS
Create/edit/delete products. Rich text description (TipTap editor). Multiple image upload (S3). Category assignment. Stock management. Featured toggle. Customizable flag (enables Design Studio for product). Bulk operations via AI Execute.
✍️ Blog CMS
Create/edit/delete blog posts. TipTap rich text editor with image embedding. Categories management. Publish/unpublish. SEO metadata (title, description, OG image).
🎟️ Coupons & Promotions
Create percentage or fixed-amount discount codes. Set minimum order value, usage limits, expiry dates. Usage analytics (how many times used, revenue impact).
👥 Customer Management
Browse registered customers and guests. View order history per customer. Convert guest accounts to member accounts. Email outreach.
⚙️ Site Settings
Store name, logo, tagline. Announcement banner (text + colour). Shipping policy, return policy, about text. Social media links. Telegram bot token configuration. Minimum free-shipping threshold.
🔍 Activity Log & Audit
Every admin action is logged: entity type, entity ID, old value (JSON snapshot), new value. Each entry can be individually rolled back. Filterable by admin user, action type, and date range.
🔒
Admin access URL: trynexshop.com/admin — protected by session token (HTTP-only cookie). Optional TOTP 2FA via authenticator app. All admin endpoints require requireAdmin middleware which validates the token hash against the admin_sessions table.

Order & Payment Flow
COD + Bangladesh mobile banking integration
🛒 Order Flow
  1. Customer adds items to cart (localStorage + optional server sync)
  2. Checkout: enter name, phone, address, district, city
  3. Select payment method
  4. Optionally enter promo code → validated against DB
  5. POST /orders creates order, returns order number
  6. Telegram bot notifies admin instantly
  7. Admin updates status as order progresses
  8. Customer tracks order at /track with order number
💳 Payment Methods
🚚 Cash on Delivery (COD) Default. Customer pays on delivery. Most popular in BD market.
📱 bKash Customer sends payment to merchant bKash number, enters transaction ID.
📱 Nagad Same flow as bKash — transaction ID submitted for admin verification.
📱 Rocket DBBL Rocket mobile banking — same verification flow.
🤖 Telegram Order Notifications
When a new order is placed, the API sends a formatted Telegram message to the admin's configured Telegram chat. Message includes: order number, customer name, phone, address, items, total, payment method. Configurable via Admin → Settings → Telegram. Tested via POST /admin/telegram/test.

Performance & Caching
PWA, Workbox, Redis, CDN edge caching
📦 Progressive Web App (PWA)

Generated by vite-plugin-pwa using Workbox. Strategies:

  • Precaching: All JS/CSS bundles, fonts, critical images
  • CacheFirst: Static assets (images, fonts) — fast loads
  • StaleWhileRevalidate: API responses — instant display, background refresh
  • NetworkFirst: Page navigations — always fresh HTML

Users can install the PWA on mobile home screen for app-like experience.

⚡ API Caching (Redis)

Upstash Redis intercepts hot GET routes:

  • GET /products — 5 min TTL
  • GET /products/featured — 10 min TTL
  • GET /settings — 30 min TTL
  • GET /blog/posts — 5 min TTL

Admin mutations (create/update/delete) flush related cache keys. Manual flush available via admin panel.
