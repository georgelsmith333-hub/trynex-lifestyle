Project Overview & Architecture

TryNex Lifestyle is a production-grade full-stack e-commerce platform built as a pnpm monorepo. It enables customers to shop standard products and design fully custom apparel in a real-time 3D studio.

🏭
Business: Bangladesh-based custom apparel and lifestyle brand. Offers T-Shirts, Hoodies, Long Sleeves, Mugs, Caps, Water Bottles in standard and fully-customised variants. Delivers across all 64 districts. Cash-on-delivery available.

Customer Account & Messaging

Registered customers get a full account dashboard at /account with five tabs.

Tab 1
👤 Profile
Edit name, email, phone. Change password. View account tier (Customer / VIP). Profile photo management.
Tab 2
📦 My Orders
Full order history with status badges, item thumbnails (including custom designs), payment status, re-order option. Filterable by status.
Tab 3
💬 Messages
Per-order threaded messaging between customer and admin.

• Lists all orders with a message preview and unread count badge
• Tapping an order opens the full message thread
• Customer can send replies (text messages)
• Auto-polled every 30s while tab is active
• Unread count reflected in navbar notification bell
Tab 4
🎁 Referrals
Unique referral link. Track referred customers and earnings. Share via WhatsApp, Facebook, copy-to-clipboard.
Tab 5
🕐 Recently Viewed
Products the customer viewed recently. Persisted per session. Quick re-access without searching again.
Notifications
🔔 Navbar Bell Badge
The navbar bell icon shows a red badge with the count of unread messages from admin. Polls /api/orders/my/messages/unread-count every 30 seconds when the user is logged in. Badge disappears immediately when the Messages tab is opened.
Order Messaging

Auto-Confirmation Message

✉️
When an order is placed: the API automatically sends a welcome message in the order thread from admin: "Thank you for your order! We have received it and will start processing shortly. If you have any questions, feel free to message us here." This ensures every customer has an active thread they can reply to.
Track Order

Guest Order Tracking

📍
Accessible at /track or /track-order (both routes work). Customers enter their order number + email or phone. Shows: 5-step status progress, payment status, ordered items with design thumbnails, delivery address, and an inline messaging thread — identical functionality to the Account Messages tab but accessible without logging in.

§ 7

Database & Storage

PostgreSQL via Drizzle ORM. 12 migrations run automatically at startup. Multi-URL failover chain ensures zero downtime if primary DB is unavailable.

Primary Database
Replit PostgreSQL
Auto-provisioned by Replit. Connection string in DATABASE_URL. Always tried first.
Failover Chain
Neon PostgreSQL
3 Neon DBs as fallback: DATABASE_URL_MAIN → DATABASE_URL_TRYNEX_DB → DATABASE_FAILOVER. Tried sequentially on primary failure.
Cache Layer
Upstash Redis
REST-based Redis for settings, product lists, and session tokens. Falls back to in-process Map when UPSTASH_REDIS_REST_TOKEN is absent.
Object Storage
Cloudflare R2
S3-compatible. Stores product images, custom design exports, AI-generated art. Credentials: R2_ACCESS_KEY_ID / R2_SECRET_ACCESS_KEY.

Security

Security Architecture

  • ✓
    Dual JWT System
    Customer auth and admin auth use separate secrets. Admin tokens never usable for customer endpoints and vice versa.
  • ✓
    httpOnly Cookies
    JWT stored in httpOnly, SameSite=Strict cookies. Not accessible via JavaScript — XSS-safe.
  • ✓
    TOTP 2FA (Admin)
    Admin accounts can enable TOTP two-factor authentication. QR code setup via /admin/totp-setup.
  • ✓
    Rate Limiting
    Login endpoints are rate-limited. Order placement has anti-bot checks.
  • ✓
    CSRF Protection
    Checkout form uses X-Requested-With header check to prevent cross-site form submissions.
  • ✓
    requireAdmin Middleware
    All /api/admin/* routes are protected by the requireAdmin middleware — 401 if missing or invalid admin token.
