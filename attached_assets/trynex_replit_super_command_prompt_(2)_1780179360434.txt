B. DESIGN STUDIO MOCKUPS — REPLACE WEAK SVG MOCKUPS
=====================================================================

Problem:
The current Design Studio uses flat grey SVG/vector mockups. It does not look like professional apparel photography. Customers cannot clearly understand final output quality.

Required fix:
1. Replace SVG illustration mockups with high-quality photorealistic garment mockups.
2. Prefer real product photography / ghost mannequin style for T-shirts, hoodies, long sleeves, caps, and mugs.
3. Keep fallback mockups if API fails, but never show broken images.
4. Mockups must support multiple product types, sides, and colours.

Best mockup strategy:
1. Short-term best: Use high-quality local/static photorealistic mockup assets for every product type and colour, stored in /public or CDN/R2. This gives instant preview and avoids API delay.
2. Medium-term: Integrate Printful Mockup Generator API for products that match Printful catalogue. This is free with Printful account but limited to Printful products and may look generic.
3. Premium future option: Add Dynamic Mockups / Mediamodifier / similar API for more realistic templates if the business needs better-than-Printful mockups.

Implementation plan:
1. Create a central mockup map/config:
   - productType: tshirt, hoodie, longSleeve, mug, cap
   - colour: white, black, navy, red, green, grey, etc.
   - side: front, back, leftSleeve, rightSleeve, neck
   - baseImageUrl
   - printableArea coordinates: x, y, width, height, rotation, perspective if needed
2. Use this config in both Design Studio and product detail pages.
3. When colour changes, update only the garment image, not the full page/card background.
4. If a variant mockup is missing, show a clean fallback and log a warning.
5. For Printful integration, create backend endpoints:
   - POST /api/mockups/printful/create-task
   - GET /api/mockups/printful/task/:taskKey
   - POST /api/mockups/generate
6. Store Printful token only in environment variables. Never expose it in frontend.
7. Upload generated design PNG to server/R2 first, then send public image_url to Printful.
8. Cache generated mockup URLs by productId + variantId + side + designHash so repeated generation does not waste API calls.
9. If API takes time, show “Generating realistic mockup…” with a skeleton loader.
10. Add retry and rate-limit handling.
